# weread

非官方的微信读书 macOS 桌面客户端。用 [Wails v3](https://v3.wails.io) 直接加载 `weread.qq.com`，再注入一层阅读增强脚本。登录、书架、同步、笔记都走官方网页，本项目不调用私有接口，也不保存书籍内容。

## 构建

依赖 Go 1.24+、Node.js、Wails v3 CLI。

```bash
go install github.com/wailsapp/wails/v3/cmd/wails3@latest
wails3 build      # 产物 bin/weread
wails3 package    # 打包 bin/WeRead.app
```

## 功能

阅读
- 沉浸模式：标题条、工具按钮、光标在阅读时自动隐藏，移动鼠标即出现
- 间距三档：紧凑 / 标准 / 宽松
- 收紧章首空白
- 版心宽度：窄 / 适中 / 宽 / 满，窗口缩放时正文跟着重排
- 纸张底色：原色 / 米黄 / 护眼 / 暗化
- 代理官方字号、字体、主题、单双栏，统一收进右下角的悬浮按钮
- 键盘翻页，读到章末自动进入下一页或下一章；自动滚动
- 启动时直接打开上次读的书

界面
- 自绘标题条：隐藏系统红绿灯，支持拖动、关闭、最小化
- 书架等页面支持日间 / 夜间 / 跟随系统
- 切换时淡入淡出；系统开了「减弱动态效果」时自动关闭动画

伪装模式
- 窗口半透明，正文改成终端配色和等宽字体，适合放在终端旁边
- `⌃⌥Space` 全局隐藏 / 显示窗口

## 实现要点

- 正文由官方引擎画在 canvas 上，CSS 无法直接改动。间距和章首空白的调整，是把规则追加到引擎读取的 `.renderTargetContainer > style` 里，再把正文栏宽度改动 1px 触发重排。
- 部分官方按钮不响应脚本合成的点击，由 Go 侧向窗口投递原生鼠标事件。
- 官方网页在系统深色模式下只改了文字颜色，所以书架页的夜间模式用反色滤镜实现，图片再反色回来。
- 窗口底色与页面底色同步，避免缩放窗口时闪白。
- 页面消息只接受 `https://weread.qq.com` 主 frame 发来的，Go 侧对取值做白名单校验。

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `main.go` | 窗口、菜单、全局快捷键、页面消息处理 |
| `config.go` | 偏好与窗口状态，存于 `~/Library/Application Support/weread-desktop/config.json` |
| `window_darwin.go` | macOS 原生调用：透明窗口、外观、底色、原生点击 |
| `inject/reader.js` | 增强脚本；官方 DOM 选择器集中在顶部的 `SEL` |
| `inject/reader.css` | 增强样式 |

官方页面改版后，先检查 `SEL` 里的选择器。
